
**核心理念**：  
**以EmoBi为骨架（简单高效的3步提示词链） + Sarcasm四篇论文的“强项补短板”**，打造**多模态情感增强双向交互框架**（暂命名为 **EmoBi-Multi**）。

EmoBi最强的是“零样本提示词+情感引导”，但它有两大短板：  
1. 情感分析纯靠LLM主观判断（容易错）  
2. 只支持纯文本、无多模态（社交媒体短视频场景弱）

我们用Sarcasm论文补刀：
- SWE → **SenticNet/HowNet情感词典向量**（精确数值情感嵌入，解决主观问题）
- MILNet → **KL互增强**（让夸张和隐喻真正“互相学习”）
- MVK → **多视角晚期融合**
- MuSaG → **全模态独立标注**（文本+音频+视频单模态标签）

**预期效果**：纯文本模式 ≈ 原EmoBi，多模态模式大概率再提升8-15% F1（因为社交媒体90%是视频！）

### 二、详细流程设计方案（4大阶段 + 时间规划）

#### **阶段1：数据准备（第1-3周，1人可完成）**
目标：构建**中英双语、多模态小数据集**（总200-300条，够本科毕设）

3. **工具**：
   - 音频转录：Whisper（免费）

#### **阶段2：模型架构设计（第3-5周）**

**整体架构图**（直接画进报告）：

```
输入（文本 + 音频 + 视频）
       ↓
【情感分析模块】 ← SenticNet/HowNet词典向量（精确） + LLM提示
       ↓
【域映射模块】 ← LLM（源域/目标域 + 情感连接）
       ↓
【双向动态交互模块】 ← 双向注意力 + KL互增强（MILNet风格）
       ↓
【多模态晚期融合】 ← MVK式注意力（文本+音频+视频特征）
       ↓
【验证机制】 ← LLM自检（冲突则重跑）
       ↓
输出：Hyperbole标签 + Metaphor标签
```

**三大模块细节**（超简单实现）：
1. **情感分析模块**（SWE升级版）
   - 先用词典（SenticNet英文 / cnsenti中文）打分每个词 → 得到情感向量
   - 再喂LLM提示词（加词典分数）

2. **域映射 + 双向交互**（EmoBi原 + MILNet升级）
   - 保留EmoBi提示词链，但加KL散度损失（让两个任务互相拉近预测）

3. **多模态融合**（MVK + Qwen2.5-VL）
   - 文本：BERT/Qwen
   - 音频：Whisper特征
   - 视频：Qwen2.5-VL 一帧或视频直接输入（超方便）
