## 2) 本轮优化动作（Stage2 重点）

- 新增 Retry Reason 分布统计：
  - explicit / auto:hypol / auto:default 的 count 与 ratio。
- 新增一致性与异常强度指标：
  - unique count、dominant、dominant count、non-dominant count、mismatch ratio、mismatch flag。
- 新增阈值告警（可配置）：
  - 参数：`--stage2-retry-reason-alert-threshold`（默认 0.05）。
  - 字段：alert threshold、alert flag、alert excess。
- 新增分级与评分：
  - alert level（none/low/medium/high）、alert score（0~3）。
- 新增复核标记：
  - needs review（score>=2）。
