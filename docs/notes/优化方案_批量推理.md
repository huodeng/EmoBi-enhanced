# 批量推理优化方案

## 1. 优化目标

将当前每个样本 4 次串行 LLM 调用合并为 1-2 次，显著提升推理速度。

## 2. 当前流程 vs 优化后流程

### 当前流程（每样本 4 次调用）
```
样本1: analyze_emo → target_source_domains → metaphor_learning → hyperbole_learning
样本2: analyze_emo → target_source_domains → metaphor_learning → hyperbole_learning
...
```

### 优化后流程（每样本 1-2 次调用）
```
Stage1 (批量): analyze_all_batch → 返回所有样本的情感+域映射+隐喻+夸张结果
Stage2 (校验): hyperbole_metaphor_batch → 对低置信度样本做联合校验
```

## 3. 批量推理 API 设计

### 3.1 批量情感+域+判断 (Stage1)

```python
def analyze_batch(texts: List[str], model_name: str) -> List[Dict]:
    """
    输入: ["text1", "text2", ...]
    输出: [{
        "emotion_reason": str,
        "target_domain": str,
        "source_domain": str,
        "metaphor_judgment": int,
        "hyperbole_judgment": int,
    }, ...]
    """
    prompt = build_batch_prompt_stage1(texts)
    response = llm_chat(prompt, model_name)
    return parse_batch_response_stage1(response, len(texts))
```

### 3.2 批量联合校验 (Stage2)

```python
def verify_batch(samples: List[Dict], model_name: str) -> List[Dict]:
    """
    对低置信度样本做二次校验
    """
    low_conf_samples = [s for s in samples if s['confidence'] < threshold]
    if not low_conf_samples:
        return samples
    prompt = build_batch_prompt_stage2(low_conf_samples)
    response = llm_chat(prompt, model_name)
    return merge_verified_results(samples, parse_batch_response_stage2(response))
```

## 4. 提示词模板

### Stage1 批量提示词

```
You are an expert at analyzing emotion, metaphor, and hyperbole in text.

For each sentence below, provide:
1. Emotion analysis reason
2. Target domain
3. Source domain
4. Metaphor judgment (0 or 1)
5. Hyperbole judgment (0 or 1)

Output format for each sentence:
[SENT{i}]
Emotion: <reason>
Target: <domain>
Source: <domain>
Metaphor: <0 or 1>
Hyperbole: <0 or 1>
[/SENT{i}]

Sentences:
1. "I'm so hungry I could eat a horse"
2. "He is a snake in the grass"
3. ...
```

### Stage2 批量校验提示词

```
Review and verify the following predictions. If wrong, correct them.

[SENT{i}]
Original: {original_text}
Metaphor: {m}, Hyperbole: {h}, Conf: {conf}
[/SENT{i}]

Output format:
[SENT{i}]
Final Metaphor: <0 or 1>
Final Hyperbole: <0 or 1>
Reason: <if changed, explain>
[/SENT{i}]
```

## 6. 风险与回退

- **风险**: 批量处理时 LLM 可能对复杂样本处理不如单样本精细
- **回退**: 如有问题，可通过参数切换回原有单样本流程
- **兼容**: 添加 `--use-batch-inference 0/1` 参数
