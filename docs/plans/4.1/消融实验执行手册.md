# 消融实验执行手册

## 1. 目标

- 用统一口径量化各模块真实贡献，回答“哪些模块有效、增益多少、是否稳健”。

---

## 2. 实验分组定义

| 分组 | 配置含义 | 主要用途 |
| --- | --- | --- |
| `wo_feature` | 关闭情感词典与概念特征注入 | 作为无显式特征基线 |
| `plus_e` | 仅开启情感词典注入 | 评估情感特征的独立贡献 |
| `plus_c` | 仅开启概念特征注入 | 评估概念特征的独立贡献 |
| `full` | 情感词典 + 概念特征 + 现有级联策略 | 作为完整方案对照 |
| `wo_cascade` | 保留特征注入，关闭 Stage-2 深度级联增强项 | 评估级联策略贡献 |

实现方式：通过 `main.py` 的 `--ablation-profile` 参数一键切换。

## 3. 执行命令

直接执行全部消融矩阵：

```powershell
python run_ablation_matrix.py --results-root results/final_runs --plan-dir results/final_tables --execute 1
```

执行后汇总指标：

```powershell
python collect_final_metrics.py --root-dir results/final_runs --out-dir results/final_tables
```

## 4. 论文主表建议

- 主表字段：`dataset, profile, hyper_f1, meta_f1, samples`
- 建议同时报告：`hyper_precision, hyper_recall, meta_precision, meta_recall`
- 监控补充：`has_stage2_guard_summary`

---


- 若 `full` 优于 `wo_feature`：说明显式特征注入总体有效。
- 若 `plus_e` 优于 `plus_c`：说明情感线索在当前数据上贡献更大。
- 若 `wo_cascade` 低于 `full`：说明级联机制提升鲁棒性。
- 若部分数据集提升不显著：应解释数据分布差异与服务波动影响，并给出复验计划。
